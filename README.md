


# International Education Costs Analysis
Descripción:
Proyecto de análisis exploratorio, segmentación y modelado predictivo sobre costos internacionales de educación superior utilizando Python, Scikit-Learn, TensorFlow y Keras.


---

Este proyecto tiene como objetivo analizar los factores que influyen en el costo total de estudiar en instituciones internacionales y construir modelos capaces de predecir dicho costo a partir de variables académicas, económicas y geográficas.

El flujo de trabajo implementa:

    Limpieza y validación de datos
    Ingeniería de variables
    Análisis exploratorio (EDA)
    Visualización estadística
    Segmentación mediante K-Means
    Modelos de Machine Learning
    Redes Neuronales con TensorFlow/Keras
    Generación automática de reportes
    Exportación de resultados para Power BI y Excel

---
